# ROOT · Network OS 1.8.0

Research, customer growth and expansion now give you more control over how the bunker develops between visits.

- **Research economy.** Agent levels add research output with diminishing returns. Routine jobs pay fewer points, starter projects cost 25–40 RP, and repeatable tracks start at 120–240 RP.
- **Customer growth.** A paid expansion reserves capacity and adds units to the existing contract after an agent provisions it. The quote identifies room team, hardware and funding constraints.
- **Unattended operations.** An optional response plan can start a safe power reroute within the hourly repair budget and protected cash reserve. Server purchases and sector expansion warn if the next backup will exceed its budget. Unaffordable enquiries skip the expensive capacity check.
- **Phased construction.** On Basement 1, the first additional server room can open with two rack slots for 6 million CR. A 14-million-CR fit-out adds four more. You can also build all six slots at once. Sector expansion counts reachable servers.
- **Agent development.** At level 14, agents can specialize in customer service, rack maintenance or project review. Automatic staffing prioritizes urgent SLA work, and job selection accounts for available resources and estimated run time.

Existing saves migrate to schema 11. Research balances, completed work and paid commitments carry over. Automatic power rerouting is off by default.

Installed Windows and Linux editions can update through **Settings → Desktop & updates**. Portable users can replace their binary and keep the adjacent save folder.

For Docker, keep the existing Compose project and volume, run `docker compose pull`, then `docker compose up -d --no-build --wait`. The versioned image is `ghcr.io/tricade/root-network-os:1.8.0`. [Docker instructions](https://github.com/Tricade/root-network-os/blob/v1.8.0/docs/docker.md).
