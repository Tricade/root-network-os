# ROOT · Network OS 1.7.1

**Coming up** now lists a rack upgrade as soon as the operator books it. An announced outage counts down to the maintenance start, then shows the time until the rack comes back online. An immediate upgrade shows the time remaining straight away. Select the rack name to open the affected cabinet in the web interface or the 3D console. The entry disappears when the work is complete.

The Docker edition uses the official Node.js **26.13.0 LTS** image on x86-64 and ARM64. The source edition supports Node.js 24 and 26, with checks on Windows and Linux for both. Installed Windows and Linux editions can update through **Settings → Desktop & updates**. Portable users can replace their binary and keep the adjacent save folder.

For Docker, keep the existing Compose project and volume, run `docker compose pull`, then `docker compose up -d --no-build --wait`. The versioned image is `ghcr.io/tricade/root-network-os:1.7.1`. [Docker instructions](https://github.com/Tricade/root-network-os/blob/v1.7.1/docs/docker.md).
