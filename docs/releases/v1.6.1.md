# ROOT · Network OS 1.6.1

This release adds the Docker browser edition alongside the existing Windows and Linux desktop downloads.

- **x86-64 and ARM64 containers:** `ghcr.io/tricade/root-network-os:1.6.1` (or `:latest`), with the complete web UI and first-person bunker. Rendering uses the browser; the container needs no GPU.
- **Persistent progress:** Compose stores the current save and previous valid backup in a separate volume. Existing browser/desktop progress can be exported and imported through Settings.
- **Local by default:** the host port binds to loopback. NAS/LAN and HTTPS proxy deployments use an explicit browser origin; ROOT still has one save per instance and no account system.
- **Predictable operation:** a non-root process, read-only runtime, health check and graceful save shutdown. Tagged images are tested natively on both architectures before publication. Dependabot tracks the pinned Node base image.

[Docker start, backup and update instructions](https://github.com/Tricade/root-network-os/blob/main/docs/docker.md)

```sh
docker compose pull
docker compose up -d --no-build --wait
```

Download [compose.yaml](https://github.com/Tricade/root-network-os/blob/v1.6.1/compose.yaml) first, then open http://127.0.0.1:18473. Keep the Compose project directory and volume when updating. Do not use `down -v` unless you intend to delete progress.

The simulation and save schema are unchanged from 1.6.0. Offline catch-up remains capped at 12 hours; running Docker does not run an unlimited server-side economy. Windows/Linux installed editions keep their existing updater; portable editions and Docker use manual updates. Desktop packages remain unsigned.
