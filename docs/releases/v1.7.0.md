# ROOT · Network OS 1.7.0

This release adds planned rack maintenance, optional customer communication and quieter notification controls across the browser, desktop and Docker editions.

- **One rack, one outage:** combine power, cooling and switch upgrades. Select one to three components; prices and work times add up, and each component gains one level when the shared window completes. Capital plans can schedule the same batch.
- **Optional customer notice:** send a simulated announcement to active customers in the rack’s room for an extra credit fee. The rack stays online for a two-minute lead time; satisfaction loss attributable to the announced outage is halved. Delivery, SLA deficits and unrelated faults still matter. Notice is off by default.
- **Maintenance communications research:** sector 4, 450 RP and two hours of lab work. Customer desk and Preventive maintenance are prerequisites. The project cuts announcement fees by 25% and lead time to one minute. It is not required for ordinary maintenance.
- **A configurable bell:** choose visibility, badge counting and automatic pop-ups independently for ten notification types. Each type has an icon. Routine jobs and backups do not add badge counts or automatic pop-ups by default. Research, hardware and construction completions appear at the bottom right, including work completed while away. Direct action feedback stays visible.
- **More predictable 3D controls:** explicitly capture the mouse, release it with Escape, or use drag-to-look. Capture changes, focus loss and released buttons clear stale input so old drag coordinates cannot move the camera after a mode change.

Existing saves migrate to schema 9. Cached older browser clients are asked to reload before writing, so they cannot discard an already paid maintenance window. Export a backup from Settings before updating; the same save format is used by desktop, browser and Docker.

Docker images: `ghcr.io/tricade/root-network-os:1.7.0` or `:latest`, for x86-64 and ARM64. With the existing Compose project, run `docker compose pull` then `docker compose up -d --no-build --wait`. Keep its persistent volume. [Docker instructions](https://github.com/Tricade/root-network-os/blob/v1.7.0/docs/docker.md).

Windows/Linux installed editions retain their updater. Portable editions and Docker use manual updates. Desktop packages remain unsigned.

Validation: all 364 automated tests, lint and formatting passed locally, plus the native Electron smoke check with real WebGL. German and English notification settings were checked in the browser at normal and narrow widths. [Verification scope](https://github.com/Tricade/root-network-os/blob/v1.7.0/docs/verification-maintenance-notifications.md).
