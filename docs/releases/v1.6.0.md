ROOT · Network OS 1.6.0 expands the bunker into an operating business: staffed customer contracts, a much larger research atlas, planned maintenance and clearer day-to-day decisions.

### Build a business that keeps running

- Customers now send enquiries. Accepted contracts reserve capacity and need an agent to provision them before they earn revenue. Terms, renewals, cancellations, complaints and expansion requests make capacity planning matter.
- Income depends on delivered services. Operating costs, spare-part deliveries, expensive room/floor construction and paid central-utility conversions give expansion lasting consequences. A failed server affects its own capacity; shared power, cooling and network dependencies determine wider outages.
- Recruit robots from a rotating roster with independent strengths and drawbacks, assign their work and preview the costs and benefits of upgrades. The interface includes 64 original robot portraits.
- Organize operating plans into focused sections for contracts, service priorities, staffing and reserves. Review spending and scheduled work before committing.

### Make longer-term choices

- Explore 96 technologies across eight research branches, plus five repeatable tracks. Research takes lab time and reserves some project throughput. Opposing specializations involve trade-offs; changing direction has a real cost.
- Track 25 achievements on their own page, including difficult long-term milestones. Current credits, lifetime earnings and recurring net income per minute are explicitly distinguished.
- Use the notification bell for pending decisions, customer requests, rewards and activity. The dashboard shows actionable details with compact paging instead of nested scrolling.

### A clearer interface and bunker

- Grouped navigation, themed dropdowns, better modal spacing, compact buttons and responsive layouts improve both the web interface and the 3D console. Research-node details open next to the task in a dialog; completed technologies show their lasting effects.
- Original artwork illustrates events, jobs, research, achievements and room construction. Room equipment, central-cooling connections and cable trays have been refined, along with doors, displays and signage.
- Walk and sprint 50% faster, with collision-safe movement and a visible sprint hint. The sidebar logo now stays visible when navigating a long menu, including smaller Electron windows and zoomed layouts.
- New installations get a first-run introduction. Existing installations receive these release notes once after updating; both remain available in the guide. English/German localization and offline summaries have also been corrected.

### Downloads and existing saves

- **Windows installer:** `ROOT-1.6.0-windows-x64-setup.exe` — includes update controls.
- **Linux installer:** `ROOT-1.6.0-linux-amd64.deb` — includes update controls.
- **Portable:** Windows EXE or Linux AppImage — update manually and retain the adjacent `ROOT-data` folder.
- `SHA256SUMS.txt` contains the download checksums. `latest.yml`, `latest-linux.yml` and the blockmap are used by installed editions for updates.

Existing saves are migrated without a reset; installed profile locations remain unchanged. **Export a backup before updating if you may want to return to 1.5.1:** the older release cannot read the new save format. Desktop and browser profiles remain separate. Packages are unsigned. See the [desktop guide](https://github.com/Tricade/root-network-os/blob/main/docs/desktop.md) for setup and update behavior.

This release also includes the build-dependency security fixes merged since 1.5.1.
